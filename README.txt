AK-47 EDUCATIONAL WEBSITE
==========================

Файлды ашу:
1. Осы папканы толық күйінде сақтаңыз.
2. index.html файлын браузермен ашыңыз.
3. assets папкасын index.html файлынан бөлек жылжытпаңыз.

Ерекшеліктері:
- Интернетсіз де жұмыс істейді.
- Негізгі қару иллюстрациясы assets/ak47.svg ішінде.
- Бөлшектердің жеке иллюстрациялары assets/parts ішінде.
- Камуфляж фон CSS арқылы жасалған.
- Бастау, Тарихы, Артқа және Жартылай шашу/жинақтау батырмалары жұмыс істейді.

Ескерту:
Бұл оқу-жобалық визуализация. Нақты қаруды бөлшектеу/жинау бойынша қадамдық нұсқаулық емес.
